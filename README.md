# Telescope.fyi-Inspired Carousel

A React implementation of the stunning carousel effect from Telescope.fyi, featuring an innovative SVG mask technique that creates a smooth wiping transition between slides.

![Carousel Demo]

## ✨ Features

- **SVG Mask Transitions**: Unique wipe effect using SVG path morphing
- **GSAP Animation**: Smooth, performant animations powered by GreenSock
- **Text Splitting Effects**: Dynamic text animations using GSAP SplitText plugin
- **Responsive Design**: Fully responsive carousel that works on all devices
- **Modern Tech Stack**: Built with React, Tailwind CSS, and GSAP

## 🛠️ Tech Stack

- **React** (v18+) - UI framework
- **Tailwind CSS** - Styling and responsive design
- **GSAP** (GreenSock Animation Platform) - Advanced animations
- **GSAP SplitText Plugin** - Text splitting and sequencing effects
- **GSAP MorphSVG Plugin** - SVG path morphing for the wipe effect
