This project is a clone for a visually stunning website that explores the concept of telescope lenses through immersive animations and interactive elements. Recognized as **GSAP's Site of the Month** for its innovative use of scroll-triggered SVG animations .

![Website Preview](https://telescope-clone.netlfy.app)

## ✨ Features

### 🔭 Lens & Telescope Concept
- **Zoom & Refraction Effects**: First section demonstrates optical zoom and light refraction physics
- **Microscope Navigation**: Scroll-based carousel that mimics a scientist rotating a microscope
- **Camera Shutter Animation**: Carousel navigation with realistic camera shutter effects

### 🎬 Advanced Animations
- **Scroll-Triggered SVG Animations**: GSAP ScrollTrigger for timeline-based animations
- **Physics-Based Interactions**: Realistic lens distortion and light behavior
- **Smooth Transitions**: Seamless animation sequencing throughout the user journey

### 🏗️ Innovative Architecture
- **Header/Footer Hybrid Component**: Single component that transforms from header to footer
- **Bottom Recap Animation**: Footer unfolds gradually to provide website summary
- **Responsive Design**: Fully optimized for all device sizes

## 🛠️ Tech Stack

| Technology | Purpose |
